# PvPKits v0.3.0 - 2026 Edition

Modern PvP plugin stack for Minecraft `1.21.8` with Kotlin `2.3`, Java `21`, Paper API, Adventure, HikariCP, and Caffeine.

## Quick Start

```bash
mvnw.cmd clean package
```

Copy the built jar:

```bash
cp target/PvPKits-0.3.0.jar plugins/
```

## Focus Areas

- Safer Paper 1.21.8 API usage
- Adventure-based text, titles, and GUI metadata
- Shared database handling for stats and rating
- Arena reset batching and safer world access
- Duel and leaderboard UX cleanup
